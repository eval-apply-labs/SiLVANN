# SiLVANN 1.x — what each release brought

The releases of major version 1, newest first. Within a major an update keeps the models and the conversations working.
The README links here for what is new; the 0.x releases are in [`v0.md`](v0.md).

## v1.0.1

A patch on 1.0.0, whose engine and libraries it keeps as they are: on Windows, the documents say what the first signed
release did, and the installer refuses Windows' own folder and says when a data folder is gone; in the UI, an answer
goes on when you leave its page, and the chat stays where you scrolled.

**Signed, and Smart App Control lets it run.** From v1.0.0 the libraries GitHub builds for a release — the evaluator
and the silicon families — and the portable app's `SiLVANN.exe` are signed by Eval Apply Consulting LTD. On a PC with
Windows 11's Smart App Control on, the portable app and the installer's libraries served a model, and the README and
[`docs/users.md`](../users.md#on-windows) no longer say they are refused. Libraries built on the PC are not signed, and
Smart App Control may still refuse them; what to do then is in the same section.

**The installer on Windows.** `install.ps1` installs under the folder it is run in, and an administrator's PowerShell
starts in `C:\Windows\System32`: it now refuses Windows' own folder, and says to run it from your own PowerShell. A
data folder on a disk since removed or wiped — named by `silvann data` or by `SILVANN_DATA` — stopped it with
PowerShell's "cannot find drive" before the models' programs were checked; it now says which folder is gone and how to
name another, and finishes.

**Leaving a page mid-answer.** A page left while an answer was being written — another address in its tab, or the
tab closed — came back frozen: the answer went on into a copy of the browser's storage the UI had already closed, the
page that came back never showed it, and the UI could stop on an `IndexError` when the conversation changed under it.
The answer now lives in the UI while it is written, and every page of that browser shows it: back in the same tab or in
a new one, it is still being written there, and the conversation is yours to go on with. The server put a conversation
away two minutes after its page last asked, even mid-answer; now it never puts away one being answered, and counts from
the answer's end. With one conversation on the card at a time, the one you left stays there until you open another;
with seats, one whose page has gone is put away 20 seconds after its last answer, which frees its seat — the UI tells
the server when a tab's last page goes (`POST /sessions/gone`). And the chat follows an answer only while you are at
the bottom: scrolled up to read the thinking, the view stays where you put it ([`docs/users.md`](../users.md),
[`docs/ui.md`](../ui.md)).

**The documents.** [`docs/inspiration.md`](../inspiration.md) adds why the angles have to stay many: a CT scanner
reconstructs nothing from one angle, so a singularity is a scanner that keeps a single one; a viewpoint earns its
weight by what it predicts, as Bayes' rule weighs a frame and a scanner's statistical reconstruction its rays; and
models trained on what earlier models generated lose the rare first.

## v1.0.0

The first release of major version 1: 0.29.1's engine, with the models and the conversations of every 0.x release
carried over as they are. An old NVIDIA card reads a prompt twice as fast through OpenCL, and the documents say what
SiLVANN is built on, what inspired it, and where Eval Apply Labs stands.

**The containers' major.** `:1-amd` and `:1-nvidia` are the newest release of major version 1, and `docker/setup.sh`
pulls them; `:0-amd` and `:0-nvidia` stay 0.29.1. A container `docker/setup.sh` made moves to 1.0.0 with its `update`,
fetched again as the README's line does, over the same folder ([`docker/README.md`](../../docker/README.md)).

**Old NVIDIA cards read a prompt faster.** The OpenCL 1.2 families — `nvidia_opencl1`, for the NVIDIA cards older than
CUDA's family takes, and `intel_opencl1_igpu` — add the routed experts' weighted sum over a prompt with a kernel of
their own: the tile the experts' matrices already ran on, each sum added onto the running one in nn's own expression,
where nn's generic kernel ran before. On a Tesla V100 the 35B reads a prompt at 160 positions a second, from 75, its
sums the same to the bit.

**The documents.** [`docs/concepts.md`](../concepts.md) is now the concepts the engine is built on — the interpreter and
the library, the engine as SICP's evaluator, how it is extended — and a new [`docs/inspiration.md`](../inspiration.md)
what inspired them: meaning as a negotiation, the map people agree on, pain and the loss, and the conversation where the
negotiation reopens. In [`docs/local_ai.md`](../local_ai.md), "As a Dipl-O-Mat" answers its hardest objection, that a
clearer-headed counterpart is also a more capable one, and "How SiLVANN positions itself" says what Eval Apply Labs
publishes — high-quality packs — and why the packer is not: a statement of intent rather than a guardrail.
